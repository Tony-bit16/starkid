# 全部页面 UI 原型说明

> 本文件描述交互与布局。食材、本地菜谱、在线搜索/详情均已按此实现；
> 看板仍使用静态示意数据，匹配、提醒与导出能力保留为后续目标。

## 1. 全局框架

### 1.1 主 App 导航

```text
                 ┌──────────────────────────────┐
                 │  MainActivity (singleTask)    │
                 │  FridgeApp / Scaffold         │
                 └──────────────┬───────────────┘
                                │
        ┌───────────────────────┼─────────────────────────┐
        │                       │                         │
┌───────▼────────┐     ┌────────▼────────┐       ┌────────▼──────────┐
│ ingredients    │     │ recipes         │       │ recipes/online    │
│ 食材库          │     │ 菜谱库           │       │ 在线搜索           │
└───────┬────────┘     └───────┬─────────┘       └────────┬──────────┘
        │                      │                          │
┌───────▼────────────┐  ┌──────▼─────────────────┐  ┌─────▼──────────────────┐
│ ingredients/detail │  │ recipes/detail/{id}    │  │ recipes/online/{mealId}│
│ /{ingredientId}     │  │ 菜谱详情                │  │ 在线菜谱详情            │
├────────────────────┤  ├────────────────────────┤  └────────────────────────┘
│ ingredients/new    │  │ recipes/new            │
│ 新增食材            │  │ 新增菜谱                │
└────────────────────┘  └────────────────────────┘
```

- 一级页（食材库/菜谱库/在线搜索）显示底部导航；详情/新增页隐藏底栏，顶部显示返回。
- 顶栏由 `FridgeApp` 统一提供，标题按当前 destination 切换。
- 系统返回键：详情/新增返回上一级；一级页退出 App。
- 切换底部 tab 使用 `saveState` / `restoreState`，保留各自滚动位置。
- 在线搜索失败只影响在线页；本地食材与菜谱仍可正常进入。

### 1.2 布局与视觉

| 项 | 规则 |
| --- | --- |
| 页面边距 | 水平 16dp，顶部 12dp，底部给底栏/导航条留 80dp |
| 卡片 | 圆角 16dp，1dp 边框，白底；不使用重阴影 |
| 主色 | 深绿 `#2F6B4F`（新鲜/主按钮） |
| 强调色 | 橙 `#D9822B`（临期/提醒） |
| 错误色 | 红 `#B3261E`（过期/错误） |
| 字体 | 标题 22sp/600，正文 14–16sp，辅助 12sp |
| 触控 | 最小 48×48dp；列表整卡可点 |

### 1.3 统一四态

每个数据页面都必须覆盖：

| 状态 | 表现 | 动作 |
| --- | --- | --- |
| Loading | 居中进度圈/骨架卡片 + “正在加载…” | 无（或取消） |
| Empty | 图标 + 标题 + 解释 + 主按钮 | 新增/返回/去菜谱 |
| Error | 错误图标 + 中文原因 + “重试” | 重试；权限类给“去设置” |
| Success | 正常内容 | 各页交互 |

禁止：

- 白屏、只显示一个空白 `LazyColumn`。
- 异常直接崩溃或只打 Log。
- 用 `Success(emptyList())` 代替空态。

### 1.4 权限与降级矩阵

| 权限/能力 | 申请时机 | 拒绝/不可用 | UI 表现 |
| --- | --- | --- | --- |
| `POST_NOTIFICATIONS`（Android 13+） | 用户首次开启“到期提醒”时 | 不崩溃，提醒关闭 | 设置卡显示“通知已关闭”，提供“去开启” |
| SAF 写文件 | 点击“导出 CSV”时 | 用户取消/失败 | 取消静默；失败 Snackbar + 重试 |
| 跨 App Provider | 看板启动/刷新时 | `SecurityException`/无数据 | 错误态“请安装/更新冰箱管家，保持同一签名” |
| 存储权限 | 不需要 | — | 不申请 `READ/WRITE_EXTERNAL_STORAGE` |

## 2. 食材列表页

- 路由：`ingredients`
- 数据：`IngredientListViewModel.uiState`
- 目标：快速看到冰箱里有什么、哪些快过期，进入详情或新增。

### 2.1 布局

```text
┌────────────────────────────────────────────┐
│ 食材库                           [+ 新增]  │  TopAppBar
├────────────────────────────────────────────┤
│ [🔍 搜索食材名称…]                          │  SearchBar
│ [全部] [临期] [过期] [蔬菜] [肉蛋] …        │  FilterChips
├────────────────────────────────────────────┤
│ ┌────────────────────────────────────────┐ │
│ │ 本周概览                                │ │  SummaryCard
│ │ 12 个批次 · 3 个临期 · 1 个已过期        │ │
│ └────────────────────────────────────────┘ │
│ ┌────────────────────────────────────────┐ │
│ │ 西红柿        [临期 · 还剩 2 天]        │ │  IngredientCard
│ │ 蔬菜 · 2 个 · 入库 11-10                │ │
│ │ 保质期 7 天                      [>]    │ │
│ └────────────────────────────────────────┘ │
│ ┌────────────────────────────────────────┐ │
│ │ 鸡蛋          [新鲜 · 还剩 12 天]       │ │
│ │ 肉蛋 · 6 个 · 入库 11-08                │ │
│ └────────────────────────────────────────┘ │
│ …                                          │
├────────────────────────────────────────────┤
│              [食材]        [菜谱]           │  BottomBar
└────────────────────────────────────────────┘
```

### 2.2 组件

| 组件 | 内容/行为 |
| --- | --- |
| `TopAppBar` | 标题“食材库”；右侧“+ 新增”图标按钮 → `ingredients/new` |
| `SearchBar` | 目标能力：搜索食材名称（后续轮次）；当前未显示 |
| `FilterChip` | 目标能力：全部/临期/过期 + 分类（后续轮次）；当前未显示 |
| `SummaryCard` | 目标能力：批次/临期/过期概览（后续轮次）；当前用“共 N 条库存”文字 |
| `IngredientCard` | 名称、分类、数量+单位、剩余天数、`FreshnessPill`；当前实现 |
| `FreshnessPill` | 绿“新鲜”/橙“临期”/红“已过期” |
| 空态 | 冰箱图标 + “冰箱还是空的” + “点击右上角新增…” |
| 错误态 | “食材加载失败” + 原因 + “重试” |
| 加载态 | 居中进度圈 + “正在加载…” |

### 2.3 交互

当前已实现：点击卡片进详情、右上角新增、计数展示、四态与重试；删除只在详情页。
以下搜索/筛选/下拉刷新为后续增强：

1. 点击卡片 → `ingredients/detail/{id}`。
2. 点击“+ 新增” → `ingredients/new`。
3. 搜索输入：本地/数据库过滤，清空恢复全部。
4. 筛选切换：与搜索组合生效；无结果显示“没有符合条件的食材”，提供“清除筛选”。
5. 下拉刷新：重新订阅 Room Flow（通常不需要，保留手动刷新入口可选）。
6. 长按卡片：本轮不做批量操作；不要放隐藏手势。
7. 删除入口不放列表页，避免误触；删除在详情页二次确认。

### 2.4 状态

| 状态 | 触发 | 展示 |
| --- | --- | --- |
| Loading | 首次订阅/重试 | 居中进度圈 + “正在加载…” |
| Empty | 数据库 0 条 | 引导新增 |
| Error | 查询异常 | 错误文案 + 重试 |
| Success | 有数据 | 概览 + 列表 |

```text
┌────────────────────────────────────────────┐

├────────────────────────────────────────────┤
│ ┌────────────────────────────────────────┐ │
│ │ 西红柿                    [临期]        │ │  HeaderCard
│ │ 蔬菜 · 2 个                             │ │
│ │ 还剩 2 天                               │ │
│ │ ████████████████░░░░  保质期进度        │ │
│ └────────────────────────────────────────┘ │
│ ┌────────────────────────────────────────┐ │
│ │ 入库时间          2026-11-10 18:30      │ │  InfoCard
│ │ 保质期            7 天                  │ │
│ │ 到期时间          2026-11-17 18:30      │ │
│ │ 当前数量          2 个                  │ │
│ │ 分类              蔬菜                  │ │
│ └────────────────────────────────────────┘ │
│ ┌────────────────────────────────────────┐ │

```

### 3.2 组件与交互

| 组件 | 行为 |
| --- | --- |
| 返回 | 返回食材列表，保留滚动位置 |
| 编辑 | 当前页切换为编辑态，复用 `IngredientForm`；保存成功后回到只读态并显示 Snackbar |
| 删除 | 底部“删除”按钮；不提供额外“更多”菜单 |
| 保质期进度条 | 目标能力：`elapsed / shelfLifeDays`；当前以“剩余 N 天”文字表达 |
| 匹配提示卡 | 后续由 `RecipeRepository.observeMatches()` 提供；当前未显示 |
| 删除按钮 | `AlertDialog`：“删除后无法恢复；菜谱定义与食材品类不会受影响。” 取消/删除 |
| 删除成功 | 返回列表，列表通过 Room Flow 自动刷新（不额外弹 Snackbar） |
| 删除失败 | 留在本页，Snackbar 错误，可重试 |

### 3.3 状态

| 状态 | 展示 |
| --- | --- |
| Loading | 头部骨架 + 信息行骨架 |
| Empty | “这批食材已被删除” + “返回列表” |
| Error | 错误文案 + 重试；若 `NotFound` 用空态 |
| Success | 上述内容 |

### 3.4 边界

- 数量为 0：仍可查看，状态显示“已用完”，删除按钮可用。
- 已过期：进度条红色，顶部显示“已过期”，不阻止查看。
- 保质期天数很大：进度条仍按比例，文字显示实际天数。

## 4. 新增食材页

- 路由：`ingredients/new`
- 数据：`AddIngredientViewModel.formState`
- 目标：最少输入完成一次入库，实时看到到期日，保存失败不丢表单。

### 4.1 布局（当前实现）

```text
┌────────────────────────────────────────────┐
│ [←] 新增食材                                │
├────────────────────────────────────────────┤
│ ┌ 基本信息 ──────────────────────────────┐ │
│ │ 名称  [例如：番茄                    ] │ │
│ │ 分类  [例如：蔬菜 / 蛋奶 / 乳制品    ] │ │
│ └────────────────────────────────────────┘ │
│ ┌ 库存信息 ──────────────────────────────┐ │
│ │ 入库时间 [2026-11-12          选择]    │ │
│ │ 保质期天数 [正整数，单位：天         ] │ │
│ │ 数量 [例如：3]      单位 [个/克/袋]    │ │
│ └────────────────────────────────────────┘ │
│ [              保存食材                  ] │
│ 数量支持小数（如 0.5 kg）；入库时间保存为  │
│ 当天 00:00 的时间戳。                      │
└────────────────────────────────────────────┘
```

- 新增页顶栏只提供返回，不在顶栏放保存按钮。
- 表单字段使用 `OutlinedTextField`，字段错误通过 `supportingText` + `isError` 展示。

### 4.2 字段与校验

| 字段 | 控件 | 规则 | 错误文案 |
| --- | --- | --- | --- |
| 名称 | 单行文本框 | 必填，trim 后 1–30 字 | “请输入食材名称” / “名称不能超过 30 个字符” |
| 分类 | 单行文本框 | 必填，trim 后 1–20 字 | “请输入食材分类” / “分类不能超过 20 个字符” |
| 入库时间 | 日期选择器 | 默认今天；不得晚于当前时间 | “入库时间不能晚于当前时间” |
| 保质期 | 数字键盘 | 必填，整数 1–36500 | “请输入整数天数” / “保质期不能超过 36500 天” |
| 数量 | 小数键盘 | 必填，> 0，≤ 1,000,000 | “数量必须大于 0” / “数量超出可记录范围” |
| 单位 | 单行文本框 | 必填，trim 后 1–10 字 | “请输入数量单位” / “单位不能超过 10 个字符” |

- 名称不弹品类选择器；保存时由 Repository 按规范化名称自动复用/创建 `IngredientType`。
- 表单不展示预计到期卡；保存成功后列表/详情按 `storedAt + shelfLifeDays` 计算并展示。
- 数量输入只过滤数字与一个小数点，允许 `0.5` 这类小数。

### 4.3 交互

1. 保存：字段校验 → 按钮进入 loading/禁用 → Repository 保存。
2. 成功：返回列表，列表通过 Room Flow 自动刷新；不额外弹 Snackbar。
3. 失败：留在表单，顶部错误横幅 + 字段错误；不清空输入。
4. 返回：直接返回列表；当前不做“放弃编辑”二次确认。
5. 日期选择：Material3 `DatePickerDialog`，只选日期，不选时间。
6. 键盘：系统默认行为；保存时由页面导航收起。

### 4.4 状态

- 初始：空表单，保存按钮可点击；点击后逐字段校验。
- 校验失败：字段级错误提示，焦点留在表单。
- 保存中：保存按钮转圈并禁用，防重复提交。
- 保存失败：恢复可编辑，顶部错误横幅 + 字段错误。

- 目标：看清需要什么、还差什么、怎么做。

### 6.1 布局

```text

│ 所需食材                                    │

│ │ 西红柿        2 个        [已备齐]      │ │  IngredientRow
│ │ 鸡蛋          3 个        [还差 2 个]   │ │
│ │ 葱            1 根        [没有]        │ │
```

### 6.2 组件与交互

| 组件 | 行为 |
| --- | --- |
| 匹配徽标 | 后续能力；当前不显示“能做/部分能做” |
| 食材行 | 名称、分类（未分类则显示“未分类”）、所需数量+单位 |
| 缺失汇总 | 后续匹配落地后展示“还差 2 种：鸡蛋、葱” |
| 做法步骤 | 按 `steps` 换行拆分，自动编号；空步骤显示“暂无做法” |
| 返回 | 回菜谱列表，保留滚动位置 |
| 编辑/删除 | 详情页底部“编辑 / 删除”；删除二次确认 |

### 6.3 状态

| 状态 | 展示 |
| --- | --- |
| Loading | 居中进度圈 + “正在加载…” |
| Empty | “菜谱不存在或已删除” + 返回列表 |
| Error | 错误文案 + 重试 |
| Success | 菜名、食材、步骤 + 编辑/删除 |

### 6.4 边界

- 食材品类被删除（RESTRICT 理论上不会发生）：该行显示“食材信息缺失”，不崩溃。
- 步骤含空行：过滤空行后重新编号。
- 长菜名：最多 2 行，超出省略；详情头部可换行。

### 6.5 新增/编辑菜谱页

- 新增路由：`recipes/new`；编辑复用同一表单，入口在菜谱详情。
- 数据：`AddRecipeViewModel.uiState` / `RecipeDetailViewModel.uiState`。
- 表单：`RecipeForm` + `RecipeFormState`。

```text
┌────────────────────────────────────────────┐
│ [←] 新增菜谱                                │
├────────────────────────────────────────────┤
│ 基本信息                                    │
│ [菜名                                   ]   │
│ 所需食材                                    │
│ ┌ 食材 1                             移除 ┐ │
│ │ [食材名称                          ]    │ │
│ │ [用量            ] [单位          ]    │ │
│ └────────────────────────────────────────┘ │
│ [＋ 添加食材]                               │
│ 做法                                        │
│ [步骤（多行，每行一步）                  ]  │
│ [保存菜谱]                                  │
└────────────────────────────────────────────┘
```

| 组件 | 行为 |
| --- | --- |
| 菜名 | 必填，1–40 字；错误显示在 `supportingText` |
| 食材行 | 名称/用量/单位；可移除；最多 30 行 |
| 添加食材 | 追加空行；至少保留 1 行 |
| 做法 | 多行输入，每个非空行保存为一步；1–30 步，总长 ≤ 4000 |
| 保存 | 校验通过后写入 Room；保存中按钮转圈并禁用 |
| 返回/取消 | 有未保存内容时直接返回，不额外拦截（本轮） |

- 空表单提交：食材区提示“请至少添加一种食材”，做法提示“请至少填写一个做法步骤”。

## 13. 交互与可访问性检查

- 所有图标按钮有 `contentDescription`；颜色不是唯一状态表达（同时有文字）。
- 列表项点击区域 ≥ 48dp；删除按钮与“保存”保持足够间距。
- 表单错误用 `supportingText` + `isError`，不只靠红框。
- 字体缩放 200% 时表单不截断；长文本可换行。
- 深色模式：使用主题语义色，不硬编码白底黑字；`StateLayouts` 与表单均走 MaterialTheme 颜色。
- 横屏/平板：内容最大宽度 720dp，避免表单过宽。
- 动效：页面切换使用默认 Navigation 动画；不要为列表做复杂共享元素动画。
